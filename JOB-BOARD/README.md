# JobBoard Pro

A professional job board website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🏠 **Home Page** - Hero section with search and featured jobs
- 🔍 **Job Search** - Advanced filtering and search functionality
- 📋 **Job Listings** - Comprehensive job listings with detailed information
- 👔 **Employer Dashboard** - Post and manage job postings
- 👤 **Candidate Dashboard** - Track applications and manage profile
- 📝 **Job Applications** - Complete application process with resume upload
- 🔐 **User Authentication** - Secure login system
- 📧 **Email Notifications** - Application confirmations and updates
- 📱 **Mobile Responsive** - Works perfectly on all devices
- 🌙 **Dark Theme** - Professional dark mode design

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
\`\`\`bash
git clone <your-repo-url>
cd job-board-pro
\`\`\`

2. Install dependencies:
\`\`\`bash
npm install
\`\`\`

3. Run the development server:
\`\`\`bash
npm run dev
\`\`\`

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
